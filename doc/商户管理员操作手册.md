# 商户管理员操作手册

本手册适用于 `merchant_admin`。商户管理员只能查看和操作所属商户的数据，能够使用哪些调控与库存功能还取决于平台授权。

## 登录与安全

1. 使用平台提供的账号、初始密码和登录地址。
2. 登录来源必须命中商户 IP 白名单。
3. 首次登录后通过顶部“修改密码”更换初始密码。
4. 密码至少 12 位，并包含大小写字母、数字和特殊符号。
5. 账号、密码和 API Key 不应通过公开聊天群传递。

## 运营总览

首页展示本商户的关键运营数据。利润为正显示绿色，亏损显示红色，零显示黑色。不同币种应分别核对，不要直接相加。

## 玩家管理

- 页面打开时，默认日期会直接显示在筛选框中。
- 可按玩家 ID、游戏和日期查询。
- 玩家详情展示余额、状态以及各币种的投注、派彩和利润。
- 查询不到玩家时，先检查日期、玩家 ID 和币种是否正确。

## 游戏记录

游戏记录用于按局核对投注和派彩。可按日期、玩家、游戏及币种筛选，并查看单局详情。导出数据会遵循当前商户权限和筛选范围。

## 数据统计

统计页用于查看投注、派彩、利润、局数、玩家数和实际 RTP。实际 RTP 的计算方式为：

```text
实际 RTP = 派彩金额 ÷ 投注金额 × 100%
```

短时间或局数很少时，实际 RTP 波动可能较大，不能仅凭少量游戏判断长期配置是否异常。

## 游戏调控

游戏调控中可以看到当前方案、目标 RTP / 中奖率、实际数据及运行状态。只有平台授权的管理员才能编辑和发布。

操作顺序：

1. 选择需要调整的游戏和币种。
2. 打开“编辑调控”。
3. 选择平台授权的预设，或在获准时填写自定义目标 RTP 和中奖率。
4. 执行精确预览，核对运行端能够达到的实际值。
5. 填写调整原因并发布。
6. 返回列表确认当前方案和目标值已经更新。

调控发布只影响之后的游戏结果，不修改历史记录。目标值代表长期概率目标，不保证单个玩家或短期内完全等于目标值。

## 玩家调控

商户管理员在获得权限后可以创建扶持或抑制任务。创建前必须核对玩家、游戏、币种、目标金额、最大局数和有效期。任务完成、取消或到期后不会继续作用。

## 库存管理

库存菜单只有在平台授权后才显示。

### 查看库存

库存按“本商户 + 游戏 + 币种”分别计算。库存详情中的当前场景是账户基础场景；具体玩家可能因活动、新手流程或玩家调控进入其他场景。

```text
可用库存 = 真实库存 - 活动可用预算 - 活动预留 - 待结算负债
```

### 调整库存

- 补充库存：增加真实库存，常用于入金或修正少记金额。
- 提取库存：减少真实库存，常用于提取资金或修正多记金额。
- 金额始终填写正数。
- 操作原因应写明资金来源、用途或对应的财务单据。

如果授权模式为 `request`，提交后需要平台审批；如果为 `direct`，授权额度以内立即执行，超过单笔或每日额度自动转为审批申请；如果为 `none`，不能发起调整。

## 库存流水与对账

只有获得流水权限时才显示库存流水菜单。对账时核对时间、游戏、币种、玩家、局号、事件类型、调整金额、调整前后库存和场景。人工调整对应事件类型为 `inventory_adjustment`。

## 操作审计

审计页展示本账号授权范围内的操作记录。发布调控、创建玩家任务、调整库存或修改白名单后，应通过审计记录确认是否成功。
