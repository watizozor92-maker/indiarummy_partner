# 商户只读账号操作手册

本手册适用于 `merchant_viewer`。只读账号用于数据查看和对账，不具备发布调控、创建玩家调控任务或调整库存的权限。

## 登录与安全

- 使用平台或商户管理员提供的账号登录。
- 登录 IP 必须命中所属商户白名单。
- 首次登录后及时修改初始密码。
- 不要与其他人员共用账号，便于审计记录准确对应操作者。

## 可以使用的功能

- 运营总览：查看本商户核心运营数据。
- 玩家管理：查询玩家和分币种统计。
- 游戏记录：查询及核对单局投注、派彩和利润。
- 数据统计：查看投注、派彩、利润、玩家数、局数和实际 RTP。
- 游戏调控：只读查看当前方案、目标和状态，不显示编辑按钮。
- 玩家调控：只读查看已有任务和执行进度，不能创建或取消。
- 库存管理：仅在平台授权后显示；能否查看流水取决于额外授权，不能调整库存。
- 操作审计：查看账号授权范围内的操作记录。

## 查询数据的基本方法

1. 先确认页面上的默认日期范围。
2. 根据需要填写玩家 ID、游戏、币种等条件。
3. 点击查询并核对结果数量。
4. 查看详情时确认商户、游戏、币种和时间是否与问题一致。
5. 导出前确认筛选条件，避免导出无关数据。

## 指标说明

```text
利润 = 投注金额 - 派彩金额
实际 RTP = 派彩金额 ÷ 投注金额 × 100%
可用库存 = 真实库存 - 活动可用预算 - 活动预留 - 待结算负债
```

利润为正显示绿色，亏损显示红色，零显示黑色。短期实际 RTP 会自然波动，应结合局数、投注金额和更长时间范围判断。

## 遇到异常时

- 看不到菜单：通常是平台尚未授权，不代表系统故障。
- 查询不到数据：检查日期、玩家、游戏和币种条件。
- 页面显示运行端离线：记录时间、游戏和币种，联系平台管理员检查游戏 API 和 master 服务。
- 数据与财务不一致：保存筛选条件，记录相关局号或流水 ID，交由商户管理员或平台管理员复核。
